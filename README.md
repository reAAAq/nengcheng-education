# 能成国际教育静态官网

原生 HTML、CSS、JavaScript，无构建步骤。网站仅展示公司、项目和案例，不收集访客信息，不含后台、表单、登录、支付、在线客服、统计脚本或外部接口。电话与邮箱只作文字展示。

## 页面与维护

- `index.html`：公司品牌横幅、公司简介与历程、项目体系、考团入口横幅、雅思与托福套餐、留学服务、客户沟通与付款记录、六张平铺成绩截图。
- `exam-tours.html`：独立考团详情，包含参考费用、八阶段线性服务流程，以及接机、酒店和考点环境照片。
- `site.css`：两页共用的全部样式。参照新东方北京站的浅色教育门户结构：白色抬头、左侧项目分类、右侧导航与品牌横幅、横向栏目入口、圆角课程卡片。采用用户选定的“海军蓝与香槟”配色：主色 `#17324D`、点缀 `#C6A16A`、页面暖白 `#F5F3EE`、横幅暖米 `#EBE3D6`；白底文字使用深蓝或深棕以保证对比度。
- `script.js`：手机导航、配置文字同步、成绩数据同步、图片查看弹层。弹层支持 Escape、关闭按钮、遮罩点击和焦点恢复。
- `config.js`：集中维护套餐价格、优惠、电话、邮箱和版权年份。
- `scores.js`：每张成绩图对应的总分与四项成绩，统一驱动预览、数字和大图说明。

首页考团仅为可点击横幅，不展开报价或流程；全部考团信息留在二级页。语言学习与留学申请不设独立页面。

## 本地查看与部署

直接打开 `index.html`，或在此目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

本地访问 <http://127.0.0.1:8765/>。所有图片、CSS、JS 使用相对路径，页面不依赖服务器接口。

- 网站：https://reaaaq.github.io/nengcheng-education/
- 仓库：https://github.com/reAAAq/nengcheng-education
- GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。
- `.qa/` 为本地参考素材与验证记录，不提交、不发布。

## 验证方式

在本地浏览器检查 1440、768、390 像素布局及 200% 根字号，验证无横向溢出；检查移动导航、跨页横幅、项目锚点、客户记录与成绩弹层及关闭后焦点恢复。检查图片/链接目标存在、脚本语法、无访客输入控件和请求接口。

内置浏览器不允许 `file://` 导航，直接文件模式通过相对路径、经典脚本和本地资源静态检查保证兼容，未在内置浏览器中进行自动实测。
