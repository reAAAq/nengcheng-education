# 能成国际教育官网

原生 HTML、CSS、JavaScript 静态官网，无构建步骤、后台、外部字体或第三方接口。首页先介绍公司及发展历程，再展示公司项目、客户成交记录区域、匿名成绩与咨询入口；考团是项目区的重点，详情独立呈现。通过 GitHub Pages 从 `main` 分支根目录自动部署。

## 页面

- `index.html`：公司品牌 Banner、公司简介与历程、项目总览、境外雅思考团、雅思题库、年度保分方案、托福面授、成交与付款记录区域、成绩平铺、咨询区。
- `exam-tours.html`：河内／曼谷境外雅思考团，双档报价与一条向下延伸的八阶段服务流程，住宿与考点照片嵌入对应节点。

语言学习、留学申请的独立页面已删除，导航与页脚对应入口已移除。机构介绍保留这两类业务说明，不再将它们作为套餐卡片。

## 线上部署

- 网站地址：https://reaaaq.github.io/nengcheng-education/
- GitHub 仓库：https://github.com/reAAAq/nengcheng-education
- 发布来源：`main` 分支的根目录。`.nojekyll` 让 GitHub Pages 直接提供原生静态文件。
- 后续修改并推送到 `main` 后，GitHub Pages 自动更新。
- 本地 `.qa/` 验收材料、已删除页面、未使用的原始海报和酒店照片不会提交到仓库。

## 查看

使用浏览器打开 `index.html`。复制或交付时保留整个目录，图片、样式、脚本与页面链接均使用相对路径。

本地预览也可在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765/>。按 `Ctrl+C` 停止服务。

## 修改内容

`styles.css` 提供基础样式，`brand-refresh.css` 保留共用组件样式；`company-home.css` 实现公司介绍优先的蓝白首页、时间线和分层项目布局；`tour.css` 控制考团页的报价、流程与照片节点，`icons.css` 提供统一 SVG 图标。`script.js` 控制手机导航、成绩卡片数据与图片弹层。项目快速导航使用原生锚点，所有方案直接呈现，无需分类筛选；禁用 JavaScript 时仍可阅读。`config.js` 集中配置：

```js

```

两档价格会同步显示在首页推荐位和考团详情页。三项优惠金额也由配置统一驱动；旧海报已移出考团页，仅保留在本地素材目录中，不上传到仓库。`phone`、`email` 集中维护联系方式，首页和考团页同步读取。电话支持点击拨号，邮箱支持打开邮件客户端；HTML 内也保留了相同的可点击联系方式，禁用脚本时仍可使用。

考团页沿用 `assets/tour-departure-v1.png`（出发主题透明背景）、`assets/tour-arrival-v1.png`（机场接机）和 `assets/study-companion-v1.png`（行前学习），是原创插画，不代表真实学员或考点。旧首页 `assets/tour-hero-v2.png` 和 `assets/campus-hero.png` 保留作版本素材，当前首页不再引用。完整生成提示词保存在 `IMAGE-PROMPTS.txt`。

公司首页按照最新素材重新组织，使用蓝白配色、克制的金色强调、公司时间线与分层项目区。考团在项目区优先呈现；题库、年度保分方案和托福面授位于后方，不占据公司首屏。

服务体系列出五项：境外雅思考团、雅思一个月题库（6,000 元）、雅思三个月题库（25,000 元）、雅思年度保分方案（50,000 元，一年题库与口语指导）、托福线下面授（国内 100,000 元，境外 80,000 元）。四个次级套餐均按用户新提供的四张海报整理；对应 `assets/package-ielts-month.jpg`、`assets/package-ielts-quarter.jpg`、`assets/package-ielts-year.jpg`、`assets/package-toefl.jpg`，可从每张卡片打开原海报。一个月题库展示月内无限更新与短期冲刺，三个月和一年题库展示小范围精简题库与一对一口语指导，托福展示 2 至 6 套题与全程面授。具体师资、服务范围及退款政策适用条件以咨询和签约条款为准。

历程采用本轮用户提供的素材：2010 年为雅思考团业务起步，2012 年为公司成立；规模扩大、业务拓展与全面升级只列阶段，不编造年份。已移除先前考团文案中的 2013 年起步表述。考团报价不含机票为 ¥12,800／人，含往返机票为 ¥15,000／人，机票随行情浮动，10 人成团，每月固定考期。新增服务与优惠均根据用户最新文案整理，具体日期、酒店、师资、优惠适用口径和陪同费用按团期确认。未使用“境外天然涨分”“大概率遇到培训考官”“安全与出分双保障”等结果保证，也未将师资描述为已经核实的现役考官；改为口语专项培训及按团期确认的师资安排。


## 客户成交与付款记录

首页在项目介绍之后预留成交与付款记录区域。当前素材中没有真实成交聊天或付款凭证，因此显示“真实记录整理中”，没有生成虚构记录或挪用成绩单充当凭证。待补充真实素材并完成授权与脱敏后，将此区替换为可放大的图片平铺；保留交易类型等必要说明，不公开个人账户、交易单号或私人联系方式。

## 验证

- 当前首页、考团页均在本地 HTTP 预览检查；1440、768、390 像素宽度下无横向溢出。
- 同样三种宽度下进行 200% 根字号放大检查，文字与按钮可换行，首屏随内容撑开。
- 验证手机菜单、咨询锚点、跨页导航、六组成绩平铺与数字匹配、图片弹层和关闭后焦点恢复。
- 验证四个项目锚点入口；四张原海报分别对应正确套餐，Escape 关闭后焦点恢复。
- 本地图片与页面链接进行文件存在性检查，JavaScript 语法检查通过，浏览器未记录页面脚本错误。
- 内置浏览器的 URL 安全策略不允许 `file://`，因此直接打开模式未在内置浏览器中自动验证；页面使用经典脚本与相对资源，不依赖服务器 API。

`.qa/` 是本地验收材料，不包含在交付压缩包中。

## 考团页流程改版

八个节点依次为：报名优惠、行前准备、抵达接机、酒店住宿、生活配套、考前准备、正式赴考、考后支持。酒店住宿节点仅保留一张双床客房照片；考前准备、正式赴考节点分别使用考点接待区、考点大厅照片。行前与接机环节使用原创 3D 插画，生活配套使用语义图标。三张实景照片均可点击查看完整原图。桌面采用两侧交替排版，手机使用左侧箭头与右侧单列内容。节点、清单、导航与按钮的装饰符号统一为内嵌 SVG 图标，蓝绿渐变线从开始延伸至底部箭头。

用户新文案中的 2 次线上行前培训、1–2 次口语培训、考试报名费、接机、五星同级双人间、早餐、转换插头、送接考、短途游玩、免费寄送和复议申诉协助已融入流程。题库组合优惠为 2000 元，已购 2.5 万元题库抵扣为 4000 元，双人报名优惠为 2800 元；未自行假定优惠叠加规则或双人减免是每人金额。

## 官方考试标识与成绩平铺

首页雅思题库和托福面授卡片使用官方矢量标识，原始图形与颜色保持不变，文件本地存储以支持离线打开：

- `assets/ielts-logo.svg`：从 [IELTS 官网](https://ielts.org/) 导航内嵌 SVG 的 `prefix__sprite-ielts-logo-white` 提取，白色官方版本置于深蓝背景。
- `assets/toefl-logo.svg`：[ETS 官网 TOEFL 标识文件](https://www.ets.org/content/dam/ets-org/Rebrand/Logos/toefl-logo-periwinkle.svg)，与 [TOEFL 官网页面](https://www.ets.org/toefl.html) 的品牌标识配置一致。

标识用于识别考试项目，不表示机构获得考试主办方授权或合作身份。成绩区六张原始截图同时呈现，`scores.js` 仍统一驱动每张卡片的数字、缩略图与放大图说明；HTML 保留相同的初始内容。
